# Hostinger upload package

Generated by `npm run export:hostinger` → `dist/admin.zip` (gitignored).
Everything here mirrors the target `public_html` layout — see
`docs/HOSTINGER-DEPLOY-PLAN.md` for the full plan.

```
deploy/hostinger/
├── api/config.sample.php   # template — create the REAL config.php on the server only
├── htaccess/root.htaccess  # → public_html/.htaccess   (HTTPS force + cache rules)
├── htaccess/api.htaccess   # → public_html/api/.htaccess (protect config.php)
└── dist/admin.zip          # build artifact — upload to public_html/admin/
```

## Upload checklist (hPanel)

1. Build: `npm run export:hostinger` (default basePath `/admin`).
2. File Manager → `public_html/` → delete `default.php` if present.
3. Create folder `admin/` → upload `dist/admin.zip` into it → right-click → **Extract**
   (the zip contains `index.html` at its root; after extracting, delete the zip).
4. Create folder `api/` → upload the 7 PHP files from `api/_v2.1-source/`.
5. In `api/`, create `config.php` from `config.sample.php` (MySQL creds from
   hPanel → Databases). Set permissions 600. Never commit it.
6. Upload `htaccess/root.htaccess` as `public_html/.htaccess` and
   `htaccess/api.htaccess` as `public_html/api/.htaccess` (enable "Show hidden
   files" in File Manager settings).
7. hPanel → SSL → install free Let's Encrypt for the domain.
8. Smoke test: `https://<domain>/admin/` loads; run
   `node scripts/verify.mjs https://<domain>/admin` from your machine.
9. Re-deploy later = repeat steps 1 + 3 only (API and htaccess untouched).
